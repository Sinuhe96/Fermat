# M1 scout — pp. 24–28 (`PROOF_of_FERMAT.pdf`, regions `P024`…`P028`)

Source: `pipeline/01-extract/regions/p024.yml` … `p028.yml` (all `status: REVIEWED`,
`signed_latex_sha256` present). All LaTeX below is copied from those signed
blocks; nothing is re-transcribed. Region ids are `P0NN-Rk`; display lines
inside a region are quoted as `d0…d7` in extraction order.

What this range is: a **single continuous algebraic block** inside printed
section `1. Khi n là số nguyên tố lớn hơn 11` (opened p. 6 R1). No Vietnamese
prose, no lemma citation, no case split: 18 regions of displayed integer
algebra. Convention that governs every page here is printed at **P009-R2**
(`\textit{Quy ước:}`): from there on the author clears denominators *in the
direction of using (7), (8), (9), (10)* and never cancels them, which is
harmless because every denominator is `m(h−b^n)^r ≢ 0 (mod n)`
(`r = 1,2,3,4`; `m ∈ {1,2,3,4,6,12}`). Everything is a congruence mod
`n^{4s+2}` (until P028-R3, which drops to mod `n^{s+1}`), with
`X := n^s·a·b·c·k`.

Chain shape of the range: the collected expansion of `R` (a chain of `=`
displays, P024–P025) → the same expression rewritten as a congruence
`≡ 0 (mod n^{4s+2})` → four further `⇒`-cycles, each reorganising the
expression so that a pair of highlighted terms merges into
`16(h^n − b^{n^2} − a^{n^2})X^4/(h−b^n)^5`, which is then replaced by
`16n[h^{n−1}+a^{n(n−1)}+b^{n(n−1)}]X^5/(h−b^n)^5` using congruence **(10)**
(P027-R3) → finally division by `X^3` and reduction to `n^{s+1}`, producing
the display that p. 29 names `(16′)`/`(16″)` and whose `X`-free part p. 29
names `H(h,b)`.
